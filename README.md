# Projectsity

An online electronics store with an Armenian-language interface, built with PHP and MySQL.

I built this project while studying Full-Stack Web Development at DiGi School in Yerevan.

## Features

- Product catalog with category navigation
- Shopping cart with an item counter
- User registration, login and logout
- Personal account page
- Wishlist
- Admin panel for managing the store
- News, About and Contact pages
- Interface designed in Armenian

## Tech stack

- **Backend:** PHP, MySQL (managed with phpMyAdmin)
- **Frontend:** HTML5, CSS3
- **Tools:** Git, GitHub, VS Code

## Project structure

```
public/
├── css/          styles
├── images/       product and site images
├── src/          models and controllers
├── views/        page templates (header, footer)
├── index.php     entry point
└── routes.php    page routing
```

## How to run locally

1. Install a local server with PHP and MySQL (for example OSPanel or XAMPP).
2. Copy the project folder into the server’s web directory and open it in the browser.
3. Create a MySQL database in phpMyAdmin and enter its connection settings in the project’s database configuration.
4. Make sure URL rewriting (`.htaccess`) is enabled on your server.
